# Soft Night Screensaver

A quiet A-Frame night scene made for soft looping visuals.

Heavy fog, warm floating lanterns, and a fox-eared silhouette standing still in the distance.

## Setup

1. Download A-Frame:
   - Go to https://aframe.io/releases/1.6.0/aframe.min.js
   - Save it as `lib/aframe.min.js`

2. Open the project with Live Server (VS Code) or any local server.

Do **not** open the HTML file directly with `file://` — it will break the local script loading.

## Notes

This is meant to be a calm, looping ambient piece. Perfect for posting short clips or leaving running as a screensaver-style background.

Made with ❤️ for the quiet hours.
